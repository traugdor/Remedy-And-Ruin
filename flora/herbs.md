# Catalogued Flora: Herbs

Source: `assets/survival/blocktypes/plant/herb.json`; variants from
`assets/survival/worldproperties/block/herb.json`. Game version 1.22.7.

These are real, well-known culinary/medicinal herbs — the game names them directly after their
real-world counterparts, so identification confidence is high for all nine.

| In-game herb | Block code | Real-world plant | Well-established herbal use |
|---|---|---|---|
| Basil | `herb-basil-*` | *Ocimum basilicum* | Culinary; traditionally anti-inflammatory, digestive aid |
| Chamomile | `herb-chamomile-*` | *Matricaria chamomilla* | Classic calming/sleep-aid tea; anti-inflammatory, mild digestive/skin soother |
| Cilantro (coriander) | `herb-cilantro-*` | *Coriandrum sativum* | Culinary; traditional digestive aid |
| Lavender | `herb-lavender-*` | *Lavandula* spp. | Calming/sleep aid, mild antiseptic, aromatherapy staple |
| Marjoram | `herb-marjoram-*` | *Origanum majorana* | Culinary; traditional digestive and mild antispasmodic use |
| Mint | `herb-mint-*` | *Mentha* spp. | Digestive aid, nausea relief, cooling/analgesic topical use |
| Saffron | `herb-saffron-*` | *Crocus sativus* | Culinary/dye; traditionally used as mood-lifting and antioxidant remedy (high cost, small doses historically) |
| Sage | `herb-sage-*` | *Salvia officinalis* | Sore throat gargle, mild antiseptic, traditional memory/cognitive folk use |
| Thyme | `herb-thyme-*` | *Thymus vulgaris* | Antiseptic, cough/respiratory remedy, culinary |

## Notes

- This block group is the most directly "ready to use" ingredient set for a remedy-crafting
  system: all nine are common, non-toxic, well-documented real herbs with straightforward,
  non-controversial traditional uses — a natural starting/tutorial-tier ingredient tier.
- Compare against `mushrooms.md` and `flowers.md` for higher-risk/higher-power ingredients
  (toxic or psychoactive) that could form a mid/late-game or "poison-adjacent" tier instead.
